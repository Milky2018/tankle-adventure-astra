七区路线、能力门与回访审查

这座城已经有一个值得保留的结构：第一次经过的传送带、橙色隔墙和炽热通道，后来都能用新能力从原处突破。最值得改善的是玩家在开关前后究竟做了什么决定、看见了什么变化，以及死亡后还要重复哪一段。

实机与概念对照能力图门怎么开七区诊断复活与回访验证边界

城市的三次展开

先沿单向物流深入并返回 A；从 B 任选三条能力线，合流后带着 Phoenix 回来；从 C 沿同一建筑的光学层、冷却层和炉心逐层深入。以下是进度图，图上的距离不代表驾驶时间。

门究竟怎么开

要判断一个机关是否有意义，可以问三个问题。玩家从哪一侧先看见限制？新能力具体改变了哪种运动或射线？离开时旧路上有什么能被认出来？下面把脚本条件和空间条件拆开，这两者需要不同的验证。

决策点运行时依据设计风险及验收方式
开局两道闸西侧按钮控制 relay-west。东侧按钮同时写入 relay-east 与 relays；在西闸仍关着的模拟状态下，东侧按钮的信号也能完成。前后顺序由空间保证。东侧按钮应只在穿过西闸后出现可用射角；门名中的复数容易让人误以为是两个开关同时供电。
三条中期远征迫击炮拾取单独要求 sorter。磁力模块跟随检修桥，轨道归位使模块从 14 降到 8。浮具没有拾取旗标；真正的门是抵达干滤床。其他两件中期装备均未列入这三件的交叉前置。拾取逻辑支持六种排列。要证明地图也支持，须在另外两件仍缺失时从 B 驾驶到每个分支、完成首次使用，再带着该能力从远端脱出。三件全有的存档无法覆盖这种承诺。
试验场合流magnet 需要磁力动作与装备；水面由浮渡支撑；load 是顶面受击的普通射击机关，触发后还写入 brake，两条传动分别前往近处配重与货运升降机。这是依次执行三个动作的空间 AND。顶面判定会拒绝从下方打来的直射；接受从上方射入的普通弹。去掉任一能力各试一次，特别检查岸角、较高货台和回线出口是否给了过早射位。仅修改武器白名单会损失寻找真实射角的玩法。
Phoenix 与吊笼Phoenix 模块要求 foundry（Overseer 的战斗标志）。橙墙 pressure 要求 Phoenix、高速且收起浮具。C 侧的 cage 按钮只显式要求 Phoenix。拆墙、抵达按钮是两个独立事件。出口串错、反侧门碰撞遗漏都可能提前接通 B–C；从屋顶回程应先见到 B 的转轮和原橙墙。
激光与反射gallery 和 core-feed 只接受激光动作。正常激光按射线、镜面和最近遮挡传播。接收器逻辑没有反射次数条件，二者的光学法线也未启用安装面背击阻挡；无遮挡的两面测试均能命中。两面命中并不证明实际能穿墙开门。要从玩家可站立处验正面直射、背面和经过镜面的射线，特别注意侧窗。若可绕解，优先给接收器做有厚度的背板或调整遮光口，让真正的破题点是找到反射角度。
热道、最终供料与停靠inner-thermal 与 coolant-return 使用红热碰撞规则（循环系统、过热、运动速度条件）；coolant-bypass 另要求先开热桥。hearth-transfer 下落与 core-feed 收光是独立信号。最后停靠要同时满足 Keeper 胜利、位置与高度，并主动交互。最终供料应由落下的配重打开射位；若从旧位已能接通馈线，普通玩家会错过整个空间推理。终点保持主动停靠，让最后一段的节奏由玩家掌握。

按区域做取舍

R1　回收铸造厂

入口斜坡第一只夹钳侦察车有专门的横移动作，第二只出现在西闸炮塔旁。原先两只均为 1 HP，未升级主炮就能在第一次冲锋前将它们消灭。升级、过热预算、让开冲锋直线三件事都不容易被体验到。

本轮已改。两只均为 1.5 HP。第一发留下受击但仍有威胁的敌车，第二发结束交战。带强化线圈回访时一发报废。保持维修站、传送带、两道闸与 Boss 的既有路线。值得实驾观察的是第二次接敌，玩家能否看见侦察车的冲锋间隙，同时找到侧移后避开炮塔弹线的位置。

R2　货运交换站

这里同时承担 B 的定位地标、两件武器的远征入口、通向花园的第三条路，以及见过却暂时打不开的橙墙。轨道车间的岔道选择和货场的 Sorter 给予不同任务；在 B 出发时，三条道路是否从驾驶高度就有区别比再加一扇门更要紧。

本轮已改。调度口原有散兵换成开局同型侦察车，保留其巡逻范围，配对一台固定炮塔。新语境是一边横躲冲锋一边管理火线。建议把车间的可动道岔、下层的分拣臂和通往干岸的坡道各放进一个自然转身就能看到的工作场景。货场的可选电池库奖励主炮线圈，升级后回走调度口应当能立刻感觉到差别。

R3　沉没花园

浮具改变了地图的连通性。它应先让玩家从安全干岸出发并亲手靠岸，然后才把同一片水域识别为回 A、返回 B 或向试验场推进的路。花坛两条导水槽与进水塞最终给装甲，属于可选照料；没有要求玩家先养花才开放主水路。

容易混淆的是同一个挡土墙上有不同高度的目的地。建议以压机基础、桥底和冷却管口分别指示三个出口，保留一处能看见来时坡道的首航回弯。验收时让带、未带磁力枪的玩家都从干路拿浮具再离开，途中不应借用后期检修梯。

R4　试验场

三种能力在一个实体工业流程中合流，这是中段最有意义的考试。问题出在因果的可见尺度。同一个 load 信号给近端 inspection-load 的分支约 2.03 秒，给远端 carrier 的分支约 8.65 秒。时间是接收信号的延迟，另外还要加机械运动；没有从正常驾驶视线看到远端装置的依据，玩家就很难把两件事联系起来。

优先用同一条货物轨迹或一道打开的长视线说明「配重落稳，下一段轨道接通」，并让缺最后一件能力的人能够从阻点原路撤回。胜利后 Phoenix 应将人送到第一次撞墙的那一侧；穿过原墙的动作比让奖励前再播一段演出更重要。

R5　静默天文台

这里的主路要学会调整射位；其余光路又分别通花园、局部回廊和可选设备。多个相似接收器出现在同一建筑很合理，但它们必须在外形或所驱动的机械上能看出用途。侧面窗口最好同时框住固定镜和结果装置。

本轮已改。校准室的散兵换成了夹钳侦察车，与会反光的 Mirror Inspector 同场。熟悉的冲锋声让玩家有理由先移动，重新找角度去处理新敌人。镜子能让人用环境破解攻击，保留这项价值还需要逐个检查直射和背射的有效位置。

R6　循环工场

核心选择是何时主动过热。没有循环系统时见到无法维持的热区，取得系统后可以保持红热穿过，冷却后才能舒适地继续开火。旁通还安排了一次先破热桥再打开冷路的回访。两个状态叠上长管道和上下层以后，很容易只被理解成不同颜色的闸门。

建议让冷侧绕行、第一次红热通过和永久冷路出口，从同一个管座露出各自的物理走向。玩家可以为战斗选择冷静绕行，也能为了更快接近目的地选择维持过热。检验价值的方法是记录第二程是否实际改变了走法，而不仅是是否点亮开关。

R7　中央熔炉

D、通 A 的深井、最终供料和 Keeper 的重试路线是四种不同的目的。D–A 能从地下重见开局压机；供料是一项会永久完成的双工具任务；到 Boss 的重试应直接到可以作决定的战位。把它们挤在相同门框与信号灯之间，会削弱前面六区带来的空间记忆。

建议让抵达 D 时先辨出压机井，再从另一个门面看见最终炉心。供料成功后沿回线从 D 的另一面出来，镜子与落下的配重应已留在身后。终战后保留安静停靠和继续探索的选择。

维修站与重复路程

玩家靠近维修站不会自动把它设为新复活点。主动操作才写入最后激活的站；死亡在该站重建。普通守军随维修或死亡重置，已击败的 Boss、已完成并记录的有限战场、已取得装备和已接通的永久信号保留。一次探索虽能连通两区，死亡后的出发站仍取决于玩家上次按过哪一台。

路线最应记录的东西何时才称得上有价值
A → Scrap Ram走已开 prototype-shortcut 与原路，对比实际遇到的普通守军、等待、再次瞄准和受闸时间。第二趟能从熟悉的压机侧面接近竞技场，保留下坡的空间辨识，跳过已解决的闸后遭遇。
B → Sorter / Overseer分别从货场 sorter-retry 和试验场 overseer-service 远端打开。记录维修后是否又过水、等载具、重打准备遭遇。两条回线分摊不同远征的成本；一次死亡不用重做另一条分支。Sorter 路须把升降机不在站时的等待算入。
C → Guardian / 深层区分回光学层的通道、garden-optical 巡检梯与冷却热桥回梯。只见到同一条管道未必知道会到哪层。出发前能看到去向或认出落脚地标。去 Guardian 和去花园取得不同回报。
D → Keeper / A完成 core-feed 再死亡一次；对比分流到 Keeper、回供料、乘 last-cage 回铸造厂的三个出站方向。重试绕过已完成的供料与有限战场，老井保留其长程回访用途。规范的 D→Keeper 10–15 秒为设计参考，本文未将其列为测得时长。

证据与下一次实驾

此次已验证。从修改后的作者数据重新生成 MoonBit 模拟输入。选用四个真实敌方实体及坐标，用 Game::fire 生成炮弹并调用 update_shots。四个战位都得到「基础两发、强化一发」。另外逐一验证了中期三件装备的六种拾取顺序、无遮挡光学接收面的两侧命中、东闸信号与配重信号的独立效果。测试中的障碍射线查询按用例为空，分支用例将车辆置于模块所在位置；这些结果只验证所述规则。

此次尚未验证。没有六次从 B 出发的完整驾驶记录，没有五场 Boss 的本轮死亡重跑计时，也没有从全部正常站位穷举光学旁路。本文中所列看不懂或过早通过的可能性，均区分了代码事实和需上车判定的部分。全图布局、必经门和重试站本轮未重排。

  1. 先验证会破坏顺序的路径。只带两种中期能力进入各试验场入口；拍到能看见目标的最前位置、能试的办法以及撤回的方向。若真能越门，先修造成越门的地形与射角。
  2. 再验证路线上可逆的选择。从 B 分别以磁力、迫击炮、浮渡开局，每条远征在未取得奖励时撤回一次；到手后从一个不同出口返回。用新鲜存档补齐其余排列，记录实际经过的 B 访问次数与是否被迫重复战斗。
  3. 最后验证玩家能读出什么。从 C、D 的正常驾驶高度记录光路首次成功、热道第二次通过，以及每个 Boss 前最后一次维修到第一次有意义操作。记录重打的敌人、必须等的载具和能预见的目的地，比单报一个平均路程更能指导修改。
